# Roco 10814 WLAN setup

The Roco 10814 WLAN Package contains a preconfigured router and an activation
code for a z21start. It does not introduce a second command protocol: after the
PC has joined the router's network, H0 Control Desk talks to the command station
through the standard Z21 LAN protocol over IPv4 UDP. The official protocol uses
UDP ports 21105 or 21106 and recommends 21105 for control applications.

## Before using H0 Control Desk

1. **Unlock the z21start once.** A z21start network interface is restricted to
   settings and firmware updates until it is unlocked. Use the activation code
   supplied with article 10814 and follow Roco's official unlock procedure with
   the Z21 Maintenance Tool for Windows or the Z21 Updater app.
2. **Wire the Z21 network.** Connect the LAN socket on the z21start command
   station to one of the yellow LAN sockets on the supplied 10814 router.
3. **Join the dedicated WLAN.** On the Windows PC, select the Z21 wireless
   network and enter the WLAN password printed underneath/on the router label.
   Keep the supplied router separate from an existing home network unless it has
   deliberately been reconfigured by someone familiar with IP networking; Roco
   warns that its delivered configuration can otherwise cause an address conflict.
4. **Check Windows networking.** Leave the PC configured to obtain an IP address
   automatically unless you intentionally use a custom Z21 network setup.

The unlock/activation code and WLAN password are secrets belonging to the
hardware. Do not enter either into H0 Control Desk, source files, logs, screenshots,
issues, or GitHub. The application does not need, request, transmit, or store them.

## Connect in H0 Control Desk

1. Open **Settings → Connection**.
2. Select **Use Roco 10814 WLAN**.
3. Verify the Z21 IPv4 address and UDP port. The factory command-station address
   is normally `192.168.0.111`, and the preferred Z21 control port is `21105`.
   Use the actual values from your installation if they were changed.
4. Save the settings. Saving only records the network choice and endpoint; it
   does not contact the command station.
5. Choose **Connect via WLAN** and confirm physical operation explicitly. The
   standalone app checks that Windows routes the saved Z21 address through an
   active wireless adapter before it opens the normal Z21 UDP transport.
6. Check the connection indicator before enabling track power or moving a train.

The WLAN checkbox describes how this computer reaches the Z21. It does not join
the Wi-Fi network, configure the router, unlock the z21start, or bypass the normal
physical-control confirmation. Wired LAN and 10814 WLAN use the same bounded Z21
UDP transport in the controller.

The preflight check sees the Windows route and adapter type, not the WLAN's SSID.
Confirm yourself that Windows is connected to the intended Z21 network. A failed
preflight leaves the physical controller unopened; correct the network and retry
instead of disabling the check.

If connection fails, confirm that Windows is currently connected to the Z21 WLAN,
the z21start is unlocked, the LAN cable is in a yellow router LAN socket, and the
saved IPv4 address/port match the command station. Return to simulation while
diagnosing the network; never use repeated movement commands as a connection test.
