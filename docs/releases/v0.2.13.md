# JochJell Controller v0.2.13

Updated on 28 September 2026 to include the routine playback timeout fix. Download the updated Windows executable or ZIP again if you installed the initial v0.2.13 build.

## Routine playback

- Routines run in the background, so their duration no longer holds the start request open or causes the 15-second acknowledgement timeout.
- Different trains can run routines concurrently while the controller continues its route and occupancy checks.
- Automation shows progress, completion, cancellation, and runtime errors, and includes a **Stop routine** button.
- A second routine for the same train is rejected while one is active. Stop commands, control changes, power-off, and dispatcher safety stops cancel active playback.
- The controller sends a stop when a routine finishes or fails. Trailing Wait blocks retain their full duration.
- This change has not been verified with ten simultaneous routines on physical hardware.

## Train visualizer

- View trains and cars as boxes following a top-down track spline, with block colors and clickable turnout indicators.
- Pan larger layouts by dragging empty space or holding Space while dragging; zoom and fit the view.
- Drag a train onto the track to set its destination. Vehicle lengths use H0 (1:87) dimensions in millimeters, including conversion of prototype lengths.
- Edit cubic Bézier curves with two draggable pull points per spline section.
- Select and move spline points, or add a point to split the selected curve.
- Set a maximum speed for a spline section. The lowest section limit currently applies to its whole connection in both directions.

## Fixes

- Opening `frontend/index.html` directly redirects to the Python dashboard at `http://127.0.0.1:8080`, preserving the selected page. The Python controller must be running.
- Clicking a spline point selects it locally without issuing a save request. Dragging saves the position when released.
- Controller connection failures now show a useful message instead of only “Failed to fetch”.
- Loading a saved layout restores both the running controller and the displayed geometry.
- Live state and fleet snapshot updates use the performance improvements already merged into main.

## Downloads

Use `JochJell-Controller-Native.exe` or extract `JochJell-Controller-Native-Windows-x64.zip`. The native edition includes the dashboard and starts in simulation mode. Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required. `SHA256SUMS.txt` contains download checksums.
