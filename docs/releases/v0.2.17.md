# JochJell Controller v0.2.17

Released on 11 October 2026. This release adds computer-connected occupancy detectors and turnouts, editable coloured track blocks, and manual train repositioning.

## Hardware connections

- Assign one or more detector inputs to each digital layout block.
- Connect occupancy detectors directly to the computer running JochJell Controller through USB/serial or a local network connection. Detector mappings and connection settings are saved per digital system.
- Connect track switches through the selected command station or a computer-connected USB/serial or network bridge.
- Hardware feedback and turnout assignments remain independent of the visual track sections used to draw the layout.

## Track block visualizer

- Assign each drawn track section to a layout block. Multiple sections can share one block and one block colour.
- Choose a separate colour for each block, split track sections to set block boundaries, and select blocks from the visualizer legend.
- Block boundaries and assignments are saved with the layout. Routing continues to use the existing node connections.

## Manual train placement

- Hold **Shift** while dragging a train marker to move it to the picked track location without running locomotive calibration.
- Regular locomotive dragging keeps its calibrated movement behavior. Standalone rolling stock can be dragged directly.
- For physical locomotives, manual placement changes the displayed position only; it does not send a movement command or report detector occupancy.

## Downloads

The release workflow builds **JochJell-Controller-Native.exe** and **JochJell-Controller-Native-Windows-x64.zip**, with **SHA256SUMS.txt** checksums. The native edition starts in simulation mode and requires Windows 10/11 x64 and Microsoft Edge WebView2 Runtime.
