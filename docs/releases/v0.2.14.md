# JochJell Controller v0.2.14

Released on 29 September 2026. This release improves the Home, Trains, and Automation pages with clearer status information and more compact panel layouts.

## Home and Automation

- Home places **Timetable & scheduler** on the left and **Layout information** on the right in the first row of the workspace.
- Automation places **Train automation** and **Route plans** side by side, with **Layout information** and **Timetable & scheduler** in a left sidebar.
- The Automation sidebar stays visible while scrolling on desktop. If its panels exceed the screen height, it scrolls independently and can receive keyboard focus.
- Paired panels stack when the available width is too small. On smaller screens the Automation sidebar uses the normal page flow.
- Timetable rows and header actions fit the narrower panels while retaining service editing, removal, and scheduler controls.
- Layout information now shows track power and three main counts: trains, occupied blocks, and active routes. Train details and electrical readings expand separately; short-circuit alerts remain visible.

## Trains

- The Overview, Locomotives, Rolling stock, Programming, and Assembler navigation stays at the top of the Trains workspace and remains visible while scrolling.
- Type a saved train's DCC address into the Selected train card to switch to that train. A matching address selects after a short pause; Enter confirms and Escape restores the current address. Missing or duplicate addresses display a message.
- Rolling stock inventory has labeled fields, consistent input styling, and a separate catalogue search.
- Train presence scans use a compact status strip with detected, unknown, and error counts. Scan failures and the limits of physical detection are shown when relevant.
- Train profile collapse controls use a chevron that reflects the expanded or collapsed state.

## System health and page cleanup

- Controller refresh messages, last sync time, API connection status, and app version are grouped in **System health**.
- Removed the redundant page-heading blocks-and-trains count and the separate footer status strip.

## Downloads

Use `JochJell-Controller-Native.exe` or extract `JochJell-Controller-Native-Windows-x64.zip`. The native edition includes the dashboard and starts in simulation mode. Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required. `SHA256SUMS.txt` contains download checksums.

The world clock controls, timetable routine dispatch fixes, and train visualizer features from v0.2.13 are included.
