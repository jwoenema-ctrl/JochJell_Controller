# JochJell Controller v0.2.15

Released on 10 October 2026. This release includes all changes since v0.2.14: personal accent colors, the Home departure board, rolling-stock decoder controls, block track triggers, and additional digital command-station profiles.

## Personalization

- Choose Graphite, Railway Blue, Teal, Violet, Copper, or a custom color in **Settings → Appearance**.
- Accents highlight active tabs, primary buttons, sliders, selected controls, and keyboard focus. Railway status and warning colors retain their meanings.
- Changes preview immediately. Save keeps your choice on the controller; discard restores the saved appearance, and reset returns to Graphite.
- Custom shades adapt to light, dark, and device-following themes for readable controls. Existing installations keep the Graphite appearance by default.

## Home departures

- Home now has an **Upcoming departures** board showing the next daily departures in dispatcher order, including services on the following model day.
- Collapse the board to a short preview or expand it to show all services. **Settings → Operations → Home departure preview** sets the collapsed count from 1 to 100; the default is 3.
- Service editing and scheduler controls remain in **Automation → Timetable & scheduler**. Existing Home panel preferences migrate from the old timetable panel to the departure board.

## Rolling stock and track triggers

- Function-equipped rolling-stock entries can use decoder function controls. Cars sharing a DCC address switch together.
- Configure **Automation → Track triggers** to run locomotive or rolling-stock functions, timed function pulses, or saved routines when a train enters a block.
- Filter triggers by train and direction, map occupancy detectors, and manage saved trigger definitions from the Automation page.
- Hardware triggering uses known train positions and planned routes to identify a passing train. Ambiguous entries are skipped and reported; confirming the train's position can resolve a pending entry.
- Trigger actions follow existing routine ownership, track-power, and feedback safeguards. See [Track triggers](https://github.com/jwoenema-ctrl/JochJell_Controller/blob/v0.2.15/docs/TRACK_TRIGGERS.md) for setup and detection limits.

## Digital command stations

- Settings offers Simulation, Roco Z21/z21/z21start, Digikeijs DR5000 in Z21 mode, Märklin CS2/CS3, ESU ECoS, and XpressNet LI-USB profiles.
- Network profiles support LAN or Wi-Fi; XpressNet uses a serial PC interface. Controls reflect the selected adapter's supported capabilities.
- Saving connection preferences does not connect to hardware. Connect activates the selected saved profile with track power off; Disconnect returns to simulation.
- Physical command-station and detector verification remains limited. See [Hardware compatibility](https://github.com/jwoenema-ctrl/JochJell_Controller/blob/v0.2.15/docs/HARDWARE_COMPATIBILITY.md) for profile requirements and capabilities.

## Downloads

Use **JochJell-Controller-Native.exe**, or extract **JochJell-Controller-Native-Windows-x64.zip**. The native edition embeds the dashboard and starts in simulation mode. Windows 10/11 x64 and Microsoft Edge WebView2 Runtime are required. **SHA256SUMS.txt** contains checksums for both downloads.

The earlier dashboard, world-clock, timetable, routine-playback, train-visualizer, and performance improvements are included.
